## 3. Architecture & Regression Guardrails
1. **No parallel AI engine or database reset**: All AI calls flow through `MenuEngineeringAiOrchestratorService` -> `SilaCulinaryAiConfiguration` / `SilaCulinaryAiUsageLog` / `sila-culinary-engine`.
2. **Authoritative calculations remain in .NET / deterministic Python math**: LLMs never produce authoritative financial totals, tax, or inventory adjustments.
3. **RBAC & Tenant Isolation**: All 14 agents and 21 registered tools validate `OrganizationId`, `PropertyId`, and `MenuEngineeringPermissions`; cost/margin data is redacted if `ViewMenuCost`/`ViewMenuMargin` is denied.
4. **Manual fallback (TEST 15)**: Every Menu Engineering screen and deterministic workflow remains 100% functional when AI is disabled or `sila-culinary-engine` is offline.
